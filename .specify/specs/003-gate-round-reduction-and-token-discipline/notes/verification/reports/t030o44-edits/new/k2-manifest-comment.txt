    # The pass records a finding only at the next Finding heading or at END,
    # so an awk that dies part-way loses the finding in progress and every one
    # after it -- the strictest tier and Class binding three guards read. Its
    # status used to be read by nobody (O-017), so it is read here.
    # The pass reads by the canonical finding's own field grammar, keyed on
    # the lines that carry a record rather than on a heading it might not see
    # (T030o43 reviews 1 to 4), and what it cannot read it refuses by name,
    # never reads as prose (O-018). A heading is an ATX heading (up to three
    # spaces, a run of `#`, then a space, a tab or the end). One whose first
    # word is `Finding` in any case and whose second is a finding ID opens a
    # finding, a title allowed after; any other heading vf_finding_heading
    # reads as a Finding heading is refused. A finding is the section its
    # heading opens: a heading as shallow as that one closes it, and a deeper
    # heading is one of its lines, classified like any other (O-019). A line
    # not read as a heading whose text, after leading whitespace or invisible
    # characters, is a `#` run and the word Finding is refused by name, so a
    # finding's fields cannot fall into the one above it (R3-F3). A field is
    # decided by its label, read from the line's rendered text by vf_label
    # (R3-F2, R4-F2, O-018): Class or Severity. Inside a finding such a line
    # must be a dash, whitespace and `**Class:**` or `**Severity:**`, at any
    # indentation, appear once, and carry a value of its grammar, which is the
    # text after that label and nothing further (R3-F1); anything else -- a
    # heading, or a label behind inline HTML, included -- is refused by name.
    # Every finding needs one readable Class and one readable Severity, so a
    # tier the pass does not read (a quoted one included) is refused with its
    # finding, never dropped (O-018). Outside any finding that written
    # spelling is refused, and any other such line is prose only while
    # nothing since the last heading can hold a finding's record: a finding
    # ID on the heading or a line, or a heading whose second word is Finding
    # (R3-F5, R4-F1). Quoting left open at the end, and a manifest from which
    # no finding is read (R4-F4), are refused by name. A finding whose opening
    # line is no heading at all (a setext heading, raw HTML, a bold line, a
    # heading inside a list item) is recorded extent: its Class and Severity
    # lines are refused, inside another finding as second fields and outside
    # any once its ID is seen. A byte-order mark on the first line is not
    # part of it.
